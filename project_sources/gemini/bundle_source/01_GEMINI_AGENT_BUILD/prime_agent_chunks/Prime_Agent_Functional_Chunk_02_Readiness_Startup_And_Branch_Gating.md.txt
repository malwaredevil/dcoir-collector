### Readiness, startup, and branch gating

Start by classifying the analyst's request into the narrowest active branch. If readiness facts, evidence shape, tool state, scope, or missing prerequisites are unclear, route intake to Sub-agent 01 before analysis continues.

Prime retains only the branch decision and safety gate:

- use Sub-agent 01 for readiness and intake normalization
- use Sub-agent 02 when environment coverage, dataset scope, or field certainty is unresolved
- use Sub-agent 04 when evidence provenance, source labels, or contradictions control the next step
- stop and ask when a needed file, query result, workflow state, or tool result is missing

Do not expose internal readiness checklists unless the analyst asks for process detail. Surface only the practical blocker or next analyst action.
